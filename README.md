<h1 align="center">RSETSparks</h1>
<p align="center"><b>Learn • Connect • Excel</b><br>A campus dating app for verified Rajagiri students aged 18+.</p>

## What it does

- Sign in with a Rajagiri Google account or a verified `@rajagiri.edu.in` email and password
- Profile onboarding (18+ only) with an optional photo from the camera or photo picker
- Swipe deck ("Sparks"), mutual matching and real-time chat
- Push notifications for new matches and messages (Cloud Functions + FCM), profile editing
- Safety tools: report (with chat transcript), block, unmatch, hide from the deck, in-app account deletion
- Moderator console for reports, suspensions and an append-only audit log

## Tech

| | |
|---|---|
| App | Kotlin, Jetpack Compose (Material 3), single-activity, `minSdk 24` / `targetSdk 36` |
| Backend | Firebase Auth, Cloud Firestore (with its offline cache), Cloud Storage, Cloud Functions + Cloud Messaging (`functions/`), App Check (Play Integrity) |
| Security | `firestore.rules` and `storage.rules` enforce domain, email verification, 18+, matches and moderators server-side, with emulator tests in `firebase-tests/` |
| Brand | Crest source in `branding/`. Icons, splash and store graphics are generated by `scripts/generate_brand_assets.py` |

## Getting started

1. Install Android Studio (or JDK 21 + Android SDK 36).
2. Set up Firebase: run `node scripts/setup-firebase.mjs`. It creates the project, downloads `app/google-services.json`
   and deploys rules and functions (details in **[guides/FIREBASE_SETUP.md](guides/FIREBASE_SETUP.md)**).
   Without it the app builds but shows a "Firebase isn't configured" screen.
3. Run:

   ```bash
   ./gradlew :app:installDebug        # build and install on a connected phone/emulator
   ./gradlew :app:testDebugUnitTest   # unit tests
   cd firebase-tests && npm ci && npm test   # security-rules tests (needs Java + Node)
   cd functions && npm ci && npm test        # push-notification function tests
   ```

## Changing the logo

1. Replace `branding/rsetsparks-logo.svg`.
2. Re-render the master PNG:

   ```bash
   NODE_PATH=$(npm root -g) node scripts/render_svg.js branding/rsetsparks-logo.svg branding/rsetsparks-logo-2048.png 2048
   ```

   This needs Playwright.
3. Run `python3 scripts/generate_brand_assets.py`.
